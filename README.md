## Featured work

### 🔬 Zero-Shot Epidemiology

**Deep Learning · Transfer Learning · Time Series · Statistical Validation · PyTorch**

A research project exploring whether deep learning can forecast the spread of **unknown pathogens without disease-specific training data**.

Built and evaluated a scalable forecasting framework across **15+ pathogen types**, benchmarking against **5 alternative models** using RMSE, MAE, confidence intervals and statistical hypothesis testing.

🏆 **Best Paper / award-winning research**

> The difficult part wasn't making the model predict.
>
> The difficult part was deciding whether the prediction deserved to be trusted.

---

### 🌾 Crop2Nutri

**Machine Learning · NLP · Reinforcement Learning · Econometrics · Big Data**

An AI-driven predictive analytics system designed around institutional food waste and resource allocation.

Combined logistic regression, NLP, reinforcement learning and econometric forecasting while processing **10,000+ kg of data across 50+ institutions**.

📉 **35% targeted waste reduction**
🚚 **25% targeted delivery improvement**

---

### 📡 SensiBELL

**Azure IoT · Anomaly Detection · Statistical Thresholding · Cloud Integration**

A real-time IoT risk monitoring system built for **500+ rural households**.

Designed statistical thresholds, anomaly detection logic and automated Azure IoT pipelines capable of delivering multi-channel alerts within seconds.

⚡ **Real-time risk monitoring**
📉 **45% reduction in accident risk**

---

### 🍽️ HungR

**HTML · CSS · JavaScript · Culinary Technology**

One of my earlier builds, and a reminder that before I started arguing with models about statistical significance, I was busy building things for humans.

HungR explores the intersection of **college dining, local caterers, affordability, nutrition and community**.

The project is also a nice snapshot of where I started before moving deeper into AI and data science.
